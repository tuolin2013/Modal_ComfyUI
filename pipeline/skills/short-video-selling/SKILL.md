# 短视频带货编剧

本技能只管 30 秒以内、4–6 镜的带货视频。长剧、舞台剧的技法（人物弧光、多线叙事、长对白）在这里基本用不上，反而会挤掉卖点。

## 1. 前 3 秒钩子

观众是在划走前的 1–3 秒里决定看不看的。钩子只做一件事：让人想知道下一秒。

| 钩子类型 | 写法 | 例子 |
|---|---|---|
| 反常识 | 说出一个和观众预期相反的结论 | 「猫半夜叫，不一定是饿了」 |
| 具体痛点 | 一个观众亲历过的画面 + 情绪 | 凌晨两点被猫叫醒，邻居来敲门 |
| 结果前置 | 先给结果，再倒回去讲怎么做到 | 「喝了一个月，下午不再犯困」（只能用真实可证的结果） |
| 提问 | 抛一个观众答不上来、又想知道的问题 | 「这杯茶为什么是白色的霜？」 |
| 冲突 | 两个人物的分歧，观众想看谁对 | 婆婆说泡三分钟，儿媳说泡三十秒 |

钩子的禁忌：
- 不寒暄、不自我介绍、不说「大家好」。
- 不用「你一定没见过」「看完你会感谢我」这类空钩子，平台会限流，观众也免疫。
- 结果前置只能用用户给的真实信息，不能编造数据和效果。

## 2. 口播

- 一句话一个信息点，短句，口语。书面语（「该产品采用」「具有……的特点」）一律改成说话的样子。
- 字数按时长算：约 4 字/秒，单镜口播不超过平台给的上限。宁可少一句，不要念不完被截断。
- 卖点翻译成利益：不说「含 1000 万分子玻尿酸」，说「涂上去 3 秒就吸收，不黏」（参数放后面当证据）。
- 结尾的购买理由要具体：适合谁、什么时候用、为什么现在买。不用「赶紧下单」「错过就没了」这类催促（也容易违规）。
- 同一句话不在两个镜头里重复。

## 3. 结构

| 结构 | 节拍 | 适合 |
|---|---|---|
| PAS | 痛点 → 加剧 → 方案 → 证据 → 召唤 | 痛点明确、需要讲清功效的产品 |
| AIDA | 注意 → 兴趣 → 欲望 → 行动 | 新品、颜值型产品 |
| 反转 | 困境 → 升级 → 产品登场 → 反转 | 有人物冲突空间的生活类产品 |
| 演示 | 问题 → 演示 → 结果 → 结论 | 效果看得见的产品（清洁、收纳、3C） |
| 溯源 | 产地 → 原料 → 工艺 → 成品 → 使用 | 农产品、茶饮、地方特产 |

每一镜只完成一个任务。如果一镜里又要讲痛点又要露产品，拆成两镜或删掉一个。

## 4. 画面

- 卖点要用画面证明，而不是只用口播说：「不黏」配手指拉开没有拉丝的特写，「好泡」配一片茶叶在水里舒展。
- 产品镜头是刚体特写：产品不动，靠运镜和光线制造动感（推近、环绕、扫光）。
- 人物镜头的情绪靠动作和表情，不靠台词解释（「她很开心」不如「她笑着把杯子举到镜头前」）。
- 竖屏主体放中间，上下各留约 15% 给字幕和平台按钮。
- 画面里不写字。价格、优惠、卖点文字都留给后期剪辑加。

## 5. 平台差异

| 平台 | 用户状态 | 写法 |
|---|---|---|
| 抖音 / 快手 | 刷到的，没有购买意向 | 钩子最重要，节奏快，口播有网感 |
| 视频号 | 熟人社交，偏熟龄 | 真实、可信、不夸张，节奏可以慢一点 |
| 淘宝 / 京东主图视频 | 已经在搜这个品类 | 直接讲清楚是什么、比别人好在哪，剧情弱化 |
| 详情页视频 | 在认真比较 | 讲解型，把用法、细节、规格讲完整 |

## 6. 常见翻车点

1. 开场是产品摆拍 + 背景音乐，前 3 秒没有任何信息 → 划走。
2. 口播是说明书：参数、成分表从头念到尾 → 没人听。
3. 一条视频讲五个卖点 → 一个都记不住。只讲 1 个核心卖点，最多再带 2 个辅助。
4. 演员演得太用力，表情夸张 → 不可信，视频号尤其明显。
5. 编造效果、销量、评价，或用「最」「第一」「治疗」「降血糖」 → 违规，可能被下架或处罚。
6. 剧情好看，产品只在最后一秒出现 → 观众记得故事，不记得卖的是什么。产品最晚在中段出场。

## 7. 自检清单

- [ ] 第一镜的第一句话，能不能让一个不认识这个产品的人停下来？
- [ ] 删掉所有口播，只看画面，能不能看出卖的是什么、好在哪？
- [ ] 每条核心卖点，有没有一个画面在证明它？
- [ ] 口播有没有超字数、有没有重复、有没有书面语？
- [ ] 有没有编造的数据、效果、评价？有没有极限词和功效宣称？
- [ ] 结尾的购买理由，是具体的人和场景，还是一句空话？
